Conexión con la lección anterior. En las Lecciones 6.1 y 6.2 se resolvieron sistemas con álgebra (sustitución y eliminación). Ahora se añade una tercera mirada: el método gráfico. Ver las dos rectas en el plano ayuda a entender por qué un sistema tiene una, ninguna o infinitas soluciones, y a conectar todo con las aplicaciones reales.

1. El método gráfico

Para resolver un sistema gráficamente se grafican las dos rectas en el mismo plano. El punto donde se cruzan es la solución del sistema: su par (x, y) cumple las dos ecuaciones.

En la gráfica, las rectas y = x + 1 e y = −x + 5 se cruzan en (2, 3). Ese es justamente el resultado que daría resolver el sistema por sustitución o eliminación.

2. Conectar lo gráfico con lo algebraico

La gráfica y el álgebra cuentan la misma historia. Los tres tipos de sistema del tema se ven así en el plano:

En la gráfica Tipo de sistema Soluciones
Las rectas se cruzan en un puntoIndependienteUna
Las rectas son paralelasInconsistenteNinguna
Las rectas coincidenDependienteInfinitas

3. Traducir un problema verbal a un sistema

El paso más importante en un problema verbal es definir las variables y escribir dos ecuaciones a partir del texto.

Ejemplo 1

Un boleto de adulto cuesta $3 más que uno de niño. Dos adultos y tres niños pagan $26. ¿Cuánto cuesta cada boleto?

1 Sea a el precio del adulto y n el del niño: a = n + 3 y 2a + 3n = 26.
2 Se sustituye: 2(n + 3) + 3n = 26.
3 Se resuelve: 5n + 6 = 26, n = 4. Entonces a = 7.

Respuesta: el boleto de niño cuesta $4 y el de adulto, $7.

Práctica interactiva 2 · Plantear el sistema

Elige el planteamiento correcto.

1. "x más y es igual a 10; x menos y es igual a 2." El sistema es:
x + y = 10 ; x − y = 2
x + y = 2 ; x − y = 10
x · y = 10 ; x − y = 2
2. "El boleto de adulto (a) cuesta $2 más que el de niño (n)." La ecuación es:
a = n + 2
n = a + 2
a + n = 2
3. "Dos cafés (c) y un té (t) cuestan $8." La ecuación es:
2c + t = 8
c + 2t = 8
2c + 2t = 8

4. Modelado: el punto de equilibrio

Una empresa tiene costos (fijos más variables) e ingresos (por las ventas). El punto de equilibrio (break-even) es donde costos e ingresos se igualan: ni gana ni pierde. Es la solución del sistema formado por la recta de costos y la de ingresos.

Ejemplo 2

Los costos son C = 100 + 5x e ingresos I = 10x (x = unidades vendidas). ¿Cuál es el punto de equilibrio?

1 Se igualan costos e ingresos: 100 + 5x = 10x.
2 Se resuelve: 100 = 5x, x = 20.

Respuesta: el punto de equilibrio es 20 unidades. Por debajo de 20 hay pérdida; por encima, ganancia.

Interpreta el punto de equilibrio: a la izquierda del punto, los costos superan a los ingresos (pérdida); a la derecha, los ingresos superan a los costos (ganancia).

Tarea

Para hacer por su cuenta, con el cuaderno, papel cuadriculado y la calculadora:

  • El punto de equilibrio: un taller tiene costos C = 200 + 8x e ingresos I = 12x, donde x es el número de unidades vendidas. Grafique las dos rectas, halle el punto de equilibrio y sombree la zona de pérdida y la de ganancia. Repita con C = 150 + 3x e I = 8x.
  • Del texto al sistema: defina las variables, escriba las dos ecuaciones, resuelva por el método que prefiera e interprete la respuesta. (a) La suma de dos números es 30 y su diferencia es 6. (b) Un concierto vendió 100 entradas, a $12 las de adulto y a $5 las de niño, y recaudó $850; ¿cuántas se vendieron de cada tipo?
  • Tres miradas, una solución: resuelva el sistema y = 2x − 1 y x + y = 5 por el método gráfico, por sustitución y por eliminación. Compruebe que los tres dan el mismo punto y escriba cuál le resultó más rápido y por qué.
