Conexión con la lección anterior. En la Lección 6.1 se resolvieron sistemas por sustitución. La sustitución es ideal cuando una variable ya está despejada; pero cuando las dos ecuaciones están en la forma ax + by = c, suele ser más rápido el método de eliminación: sumar las ecuaciones para que una variable desaparezca.

1. El método de eliminación

La idea es lograr que los coeficientes de una variable sean opuestos (por ejemplo, +y y −y) para que, al sumar las ecuaciones, esa variable se elimine. A veces ya están opuestos; otras veces hay que multiplicar una o ambas ecuaciones.

Ejemplo 1 · Coeficientes ya opuestos

Resolver: x + y = 10 y x − y = 4.

1 Se suman las dos ecuaciones: (x + y) + (x − y) = 10 + 4.
2 La y se elimina: 2x = 14, así que x = 7.
3 Se halla y: 7 + y = 10, y = 3.

Solución: (7, 3).

Ejemplo 2 · Multiplicar una ecuación

Resolver: 2x + 3y = 13 y x − y = −1.

1 Se multiplica la segunda por 3: 3x − 3y = −3.
2 Se suma a la primera: (2x + 3y) + (3x − 3y) = 13 + (−3).
3 Se elimina la y: 5x = 10, x = 2.
4 Se halla y: 2 − y = −1, y = 3.

Solución: (2, 3).

Ejemplo 3 · Multiplicar ambas

Resolver: 2x + 3y = 7 y 3x + 2y = 8.

1 Para eliminar x: la primera por 3 (6x + 9y = 21) y la segunda por 2 (6x + 4y = 16).
2 Se restan: 5y = 5, y = 1.
3 Se halla x: 2x + 3(1) = 7, x = 2.

Solución: (2, 1).

2. Clasificar los sistemas

No todos los sistemas tienen exactamente una solución. Según cómo sean las dos rectas, hay tres tipos:

Clasificación de sistemas según el número de soluciones.
Tipo Rectas Soluciones Al resolver aparece…
IndependienteSe cruzan en un puntoUna soluciónx = … , y = …
InconsistenteParalelasNingunaAlgo falso (p. ej. 0 = 5)
DependienteLa misma rectaInfinitasAlgo siempre cierto (0 = 0)
El resultado avisa del tipo: si al eliminar las dos variables queda una igualdad falsa (como 0 = 5), el sistema es inconsistente; si queda una igualdad siempre cierta (0 = 0), es dependiente.

3. ¿Sustitución o eliminación?

Ambos métodos llevan a la misma solución; lo importante es elegir el más rápido para cada sistema.

Cuándo conviene usar sustitución y cuándo eliminación.
Conviene… Cuándo
SustituciónCuando una variable ya está despejada o tiene coeficiente 1 o −1.
EliminaciónCuando las dos ecuaciones están en la forma ax + by = c y los coeficientes se alinean fácilmente.

4. Aplicación: mezclas, monedas y velocidades

Ejemplo 4 · Monedas

Hay 12 monedas, unas de 5¢ y otras de 10¢, que suman 95¢. ¿Cuántas hay de cada una?

1 Sea n el número de monedas de 5¢ y d el de 10¢: n + d = 12 y 5n + 10d = 95.
2 Se divide la segunda entre 5: n + 2d = 19.
3 Se resta la primera: d = 7. Entonces n = 5.

Respuesta: 5 monedas de 5¢ y 7 de 10¢.
