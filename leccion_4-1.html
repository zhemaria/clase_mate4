Lección 4.1 · Resolver ecuaciones cuadráticas por factorización

4 horas (2 sincrónicas + 2 asincrónicas) · NRS 4–5 · Brightspace D2L

Objetivos de la lección

  • Comprender y aplicar la Propiedad del Producto Cero.
  • Resolver ecuaciones cuadráticas por factorización con un procedimiento de cinco pasos.
  • Llevar una ecuación a la forma estándar ax² + bx + c = 0 antes de factorizar.
  • Resolver problemas aplicados y verificar ambas soluciones en la ecuación original.

Conexión con el tema anterior. En el Tema 3 se aprendió a factorizar polinomios. Esa destreza ahora cobra un propósito poderoso: resolver ecuaciones . Una ecuación cuadrática es una igualdad con un término x²; resolverla significa hallar los valores de x que la hacen cierta. La factorización, junto con una propiedad muy sencilla del número cero, abre la puerta a esas soluciones.

1. La Propiedad del Producto Cero

El número cero tiene una propiedad única en la multiplicación:

Si A · B = 0, entonces A = 0 o B = 0.

En palabras: si el producto de dos cantidades es cero, al menos una de ellas tiene que ser cero. No hay otra manera de que un producto dé cero.

Idea con números

Si 7 · B = 0, ¿cuánto vale B? Necesariamente B = 0, porque 7 no es cero. Lo mismo ocurre con factores que contienen x: si (x − 2)(x + 5) = 0, entonces (x − 2) = 0 o (x + 5) = 0.

La clave es el cero: esta propiedad solo funciona cuando el producto es igual a cero . Por eso, antes de aplicarla, la ecuación debe estar igualada a cero (forma estándar). Si está igualada a otro número, no se puede usar todavía.

2. Los cinco pasos

Para resolver una ecuación cuadrática por factorización se sigue siempre este procedimiento:

Los cinco pasos para resolver una ecuación cuadrática por factorización.
Paso Acción
1 Llevar la ecuación a la forma estándar: ax² + bx + c = 0.
2 Factorizar el lado izquierdo.
3 Igualar cada factor a cero.
4 Resolver cada ecuación lineal.
5 Verificar ambas soluciones en la ecuación original.
Ejemplo 1

Resolver x² + 5x + 6 = 0.

1 Ya está en forma estándar.
2 Se factoriza: (x + 2)(x + 3) = 0.
3 Se iguala cada factor a cero: x + 2 = 0 o x + 3 = 0.
4 Se resuelve: x = −2 o x = −3.
5 Verificación: (−2)² + 5(−2) + 6 = 4 − 10 + 6 = 0. Correcto.

Soluciones: x = −2 y x = −3.

Ejemplo 2 · Con diferencia de cuadrados

Resolver x² − 9 = 0.

1 Ya está en forma estándar.
2 Se factoriza: (x + 3)(x − 3) = 0.
3 x + 3 = 0 o x − 3 = 0.
4 x = −3 o x = 3.

Soluciones: x = 3 y x = −3.

3. Llevar a la forma estándar primero

Muchas ecuaciones no vienen igualadas a cero. El paso 1 es siempre reorganizarlas pasando todos los términos a un lado.

Ejemplo 3

Resolver x² = 9.

1 Forma estándar: x² − 9 = 0.
2 Se factoriza: (x + 3)(x − 3) = 0.
3 x = 3 o x = −3.

Soluciones: x = 3 y x = −3.

Ejemplo 4 · El cero como solución

Resolver x² = 5x.

1 Forma estándar: x² − 5x = 0.
2 Factor común: x(x − 5) = 0.
3 x = 0 o x − 5 = 0.
4 x = 0 o x = 5.

Soluciones: x = 0 y x = 5.

No dividas entre x: en x² = 5x, dividir ambos lados entre x haría perder la solución x = 0. Siempre se lleva todo a un lado y se factoriza; así no se pierde ninguna solución.

4. Aplicación: problemas de área

Las ecuaciones cuadráticas modelan situaciones reales, especialmente de área y de movimiento. En estos problemas hay que interpretar las soluciones: a veces una de ellas no tiene sentido en el contexto.

Ejemplo 5

El área de un rectángulo es de 54 m². El largo mide 3 m más que el ancho. ¿Cuánto mide cada lado?

1 Sea x el ancho. El largo es x + 3. El área: x(x + 3) = 54.
2 Forma estándar: x² + 3x − 54 = 0.
3 Se factoriza: (x + 9)(x − 6) = 0.
4 x = −9 o x = 6.
5 Una longitud no puede ser negativa, así que x = 6.

Respuesta: el ancho mide 6 m y el largo, 9 m.

Interpreta el contexto: en problemas de longitudes, tiempos o cantidades, se descartan las soluciones negativas o sin sentido físico. Siempre vale la pena preguntarse: ¿esta solución es posible en la situación real?

5. Práctica guiada en clase

Las siguientes tres actividades se realizan durante las horas sincrónicas. Cada una se presenta en doble modalidad.

Actividad 1 · ¿Dos soluciones, una o ninguna?

🏫 Presencial

Los estudiantes resuelven ocho ecuaciones por factorización, incluyendo casos que hay que reorganizar primero (x² = 9 y x² = 5x). En cada una identifican cuántas soluciones distintas obtienen y por qué.

💻 En línea

Cada estudiante resuelve la lista en un documento compartido, anotando los cinco pasos, y publica en el chat un caso donde una de las soluciones haya que descartarla o donde aparezca x = 0.
Actividad 2 · El rectángulo

🏫 Presencial

En parejas, los estudiantes resuelven el problema del rectángulo cuyo largo es 3 más que el ancho y cuya área es 54, y explican por qué se descarta la solución negativa.

💻 En línea

En salas pequeñas, cada grupo plantea la ecuación del problema de área, la resuelve por factorización e interpreta cuál solución corresponde a una medida real.
Actividad 3 · Siempre verifico

🏫 Presencial

El docente entrega soluciones ya resueltas, algunas con errores. Los estudiantes verifican cada solución sustituyéndola en la ecuación original y corrigen las que no cumplan la igualdad.

💻 En línea

Cada estudiante verifica tres soluciones sustituyéndolas en su ecuación, marca cuáles son correctas y describe en una frase el error de las incorrectas.
