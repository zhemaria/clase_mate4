Lección 4.3 · La fórmula cuadrática, el discriminante y aplicaciones

4 horas (2 sincrónicas + 2 asincrónicas) · NRS 4–5 · Brightspace D2L

Objetivos de la lección

  • Aplicar la fórmula cuadrática para resolver cualquier ecuación cuadrática.
  • Identificar correctamente los valores de a, b y c.
  • Usar el discriminante (b² − 4ac) para predecir el número de soluciones reales.
  • Resolver problemas aplicados e interpretar las soluciones en su contexto.

Conexión con la lección anterior. En la Lección 4.2 se vio que completar el cuadrado en la ecuación general produce la fórmula cuadrática. Ahora se usará esa fórmula directamente: con ella se resuelve cualquier ecuación cuadrática, se factorice o no. En esta lección se permite el uso de la calculadora y de la hoja de fórmulas del GED.

1. La fórmula cuadrática

Para cualquier ecuación en forma estándar ax² + bx + c = 0, las soluciones son:

x = (−b ± √(b² − 4ac)) / 2a

El primer paso siempre es identificar a, b y c con sus signos. Por ejemplo, en 2x² − 4x − 3 = 0: a = 2, b = −4, c = −3.

Cuida los signos de b y c: el valor de b incluye su signo. En −b, un b negativo se vuelve positivo. Sustituir con paréntesis —por ejemplo (−4)²— evita los errores de signo más frecuentes.

2. El discriminante: ¿cuántas soluciones?

La parte de la fórmula que está dentro de la raíz, b² − 4ac, se llama discriminante. Su signo revela cuántas soluciones reales tiene la ecuación antes de resolverla:

Relación entre el signo del discriminante y el número de soluciones reales.
Discriminante b² − 4ac Número de soluciones reales
mayor que 02 soluciones distintas
igual a 01 solución (doble)
menor que 00 soluciones reales
Ejemplo 1

¿Cuántas soluciones tiene x² + 3x + 5 = 0?

1 a = 1, b = 3, c = 5.
2 Discriminante: (3)² − 4(1)(5) = 9 − 20 = −11.
3 Como −11 < 0, no hay soluciones reales.

Respuesta: ninguna solución real.

Calcula el discriminante primero: antes de resolver, pregúntate "¿cuántas soluciones espero?". Así sabrás si la ecuación tiene dos, una o ninguna, y detectarás errores si tu resultado no coincide con esa predicción.

3. Resolver con la fórmula

Ejemplo 2 · Soluciones enteras

Resolver x² + 5x + 6 = 0 con la fórmula.

1 a = 1, b = 5, c = 6.
2 Discriminante: 5² − 4(1)(6) = 25 − 24 = 1.
3 x = (−5 ± √1) / 2 = (−5 ± 1) / 2.
4 x = −2 o x = −3.

Soluciones: x = −2 y x = −3.

Ejemplo 3 · Con calculadora (raíz no exacta)

Resolver 2x² − 4x − 3 = 0.

1 a = 2, b = −4, c = −3.
2 Discriminante: (−4)² − 4(2)(−3) = 16 + 24 = 40.
3 x = (4 ± √40) / 4. Con calculadora, √40 ≈ 6.32.
4 x ≈ (4 + 6.32) / 4 ≈ 2.58 o x ≈ (4 − 6.32) / 4 ≈ −0.58.

Soluciones (aproximadas): x ≈ 2.58 y x ≈ −0.58.

4. Aplicación: la trayectoria de un proyectil

Las funciones cuadráticas modelan la altura de un objeto lanzado al aire. Si h(t) es la altura (en pies) a los t segundos, resolver h(t) = 0 indica cuándo toca el suelo, y resolver h(t) = un valor indica cuándo alcanza esa altura.

Ejemplo 4

Una pelota se lanza y su altura es h(t) = −16t² + 96t + 5. ¿Cuándo toca el suelo? (usar calculadora)

1 Tocar el suelo significa h(t) = 0: −16t² + 96t + 5 = 0.
2 a = −16, b = 96, c = 5.
3 Discriminante: 96² − 4(−16)(5) = 9216 + 320 = 9536. √9536 ≈ 97.65.
4 t = (−96 ± 97.65) / (−32).
5 Se descarta la raíz negativa; queda t ≈ 6.05.

Respuesta: la pelota toca el suelo a los 6.05 segundos, aproximadamente.

Interpreta el contexto: en problemas de tiempo y altura, las soluciones negativas no tienen sentido (el tiempo no es negativo). La solución válida es la que corresponde a la situación real descrita.

5. Tres métodos: ¿cuál conviene?

Ya se conocen tres formas de resolver una ecuación cuadrática. Saber elegir ahorra tiempo:

Comparación de los tres métodos para resolver ecuaciones cuadráticas y cuándo conviene cada uno.
Método ¿Cuándo conviene?
FactorizaciónCuando el trinomio se factoriza fácilmente con enteros.
Completar el cuadradoCuando a = 1 y b es par; útil para entender la estructura.
Fórmula cuadráticaSiempre funciona; ideal cuando no se factoriza o las raíces no son enteras.

6. Práctica guiada en clase

Las siguientes tres actividades se realizan durante las horas sincrónicas, con calculadora y hoja de fórmulas. Cada una se presenta en doble modalidad.

Actividad 1 · El proyectil

🏫 Presencial

Con h(t) = −16t² + 96t + 5, los estudiantes calculan cuándo la pelota toca el suelo y cuándo alcanza 120 pies, interpretando las soluciones en el contexto del lanzamiento.

💻 En línea

Cada estudiante resuelve el problema del proyectil en un documento compartido y publica en el chat la interpretación de cada solución en segundos.
Actividad 2 · ¿Cuántas soluciones espero?

🏫 Presencial

Antes de resolver, los estudiantes clasifican seis ecuaciones según el discriminante (dos, una o ninguna solución) y luego comprueban su predicción resolviendo con la fórmula.

💻 En línea

Cada estudiante calcula el discriminante de las seis ecuaciones en una hoja compartida, predice el número de soluciones y verifica resolviendo las que tengan solución real.
Actividad 3 · El método más eficiente

🏫 Presencial

El grupo recibe una lista mixta y, para cada ecuación, decide y justifica qué método conviene: factorización o fórmula. Luego la resuelve por el método elegido.

💻 En línea

En salas pequeñas, cada grupo etiqueta cada ecuación con el método más eficiente, la resuelve y comenta por qué esa elección ahorró tiempo.
