Conexión con el tema anterior. En el Tema 6, la solución de un sistema de ecuaciones era un punto. En el Tema 7 las igualdades (=) se cambian por desigualdades (<, ≤, >, ≥), y la solución ya no es un punto sino toda una región del plano: muchos puntos cumplen las condiciones a la vez.

1. Graficar una desigualdad lineal

Graficar una desigualdad tiene dos partes: la línea frontera y el sombreado del lado correcto.

Cómo dibujar la línea frontera según el símbolo de la desigualdad.
Símbolo Línea frontera
< o >Punteada (la frontera no se incluye)
≤ o ≥Sólida (la frontera sí se incluye)

En la gráfica, y ≤ x + 1 tiene línea sólida (por el ≤) y se sombrea el lado de abajo, donde está el punto de prueba (0, 0).

2. El método del punto de prueba

Para decidir qué lado de la recta se sombrea, se elige un punto de prueba que no esté sobre la recta —casi siempre (0, 0)— y se sustituye en la desigualdad.

Ejemplo 1

Graficar 2x + y > 4.

1 La línea es punteada (por el símbolo >).
2 Se prueba (0, 0): 2(0) + 0 > 4, es decir 0 > 4. Falso.
3 Como es falso, se sombrea el lado contrario al origen.
Si el punto de prueba cumple la desigualdad, se sombrea su lado; si no la cumple, se sombrea el lado contrario. Si la recta pasa por (0, 0), se usa otro punto, como (1, 0).

3. El sistema de desigualdades: la región factible

Un sistema de desigualdades se grafica desigualdad por desigualdad. La región factible es la zona donde se traslapan todos los sombreados: la intersección de los semiplanos. Cualquier punto de esa región cumple todas las desigualdades a la vez.

El triángulo sombreado es la región factible del sistema x ≥ 0, y ≥ 0 y x + y ≤ 4. Todos sus puntos cumplen las tres condiciones.

4. Verificar si un punto pertenece a la región

Para comprobar si un punto está en la región solución, se sustituye en todas las desigualdades del sistema. Si las cumple todas, pertenece a la región; si falla en una, no.

Ejemplo 2

¿Está (1, 1) en la región del sistema y ≤ x + 1 ; y ≥ 0?

1 Primera: 1 ≤ 1 + 1, es decir 1 ≤ 2. Verdadero.
2 Segunda: 1 ≥ 0. Verdadero.

Respuesta: sí, (1, 1) pertenece a la región.

  • El presupuesto de producción: un taller fabrica x sillas e y mesas. Cada silla lleva 2 horas y cada mesa 4, y hay como máximo 40 horas (2x + 4y ≤ 40). Cada silla usa 1 tabla y cada mesa 3, y hay 24 tablas (x + 3y ≤ 24). Además, x ≥ 0 e y ≥ 0. Grafique el sistema, sombree la región factible y escriba tres combinaciones (x, y) que sí se pueden fabricar y una que no.
  • Sólida o punteada: para cada desigualdad, decida cómo se traza la línea y qué lado se sombrea, usando el punto de prueba (0, 0): y > 2x − 1; y ≤ −x + 3; 2x + y ≥ 4; x − y < 2; y ≥ 3; x < −1.
