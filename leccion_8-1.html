Lección 8.1 · Funciones cuadráticas: la parábola, el vértice y los interceptos

Unas 4 horas, a su ritmo · NRS 4–5

Objetivos de la lección

  • Reconocer que f(x) = ax² + bx + c se grafica como una parábola que abre hacia arriba (a > 0) o hacia abajo (a < 0).
  • Calcular el vértice (x = −b/2a) y el eje de simetría de una parábola.
  • Encontrar los interceptos con los ejes (x con la fórmula cuadrática; y con x = 0).
  • Usar el vértice para resolver problemas de máximo y mínimo.

1. La parábola y su forma

La gráfica de una función cuadrática es una parábola. El signo de a decide hacia dónde abre:

2. El vértice y el eje de simetría

El vértice es el punto más alto o más bajo de la parábola. Su coordenada x se halla con la fórmula, y la y se obtiene evaluando la función. El eje de simetría es la recta vertical que pasa por el vértice.

x del vértice = −b / (2a)  ·  eje de simetría: x = −b / (2a)

Ejemplo 1

Hallar el vértice y el eje de f(x) = x² − 4x + 3.

1 Aquí a = 1, b = −4. La x del vértice: −(−4) / (2·1) = 4/2 = 2.
2 La y del vértice: f(2) = (2)² − 4(2) + 3 = 4 − 8 + 3 = −1.
3 Vértice (2, −1); eje de simetría x = 2; como a > 0, es un mínimo.

3. Los interceptos con los ejes

Los interceptos son donde la parábola cruza los ejes:

Cómo encontrar los interceptos de una parábola.
Intercepto Cómo se halla
Con el eje yEvaluar f(0) = c. Da el punto (0, c).
Con el eje xResolver ax² + bx + c = 0 (factorizar o fórmula cuadrática del Tema 4).
Ejemplo 2

Interceptos de f(x) = x² − 4x + 3.

1 Con y: f(0) = 3, así que (0, 3).
2 Con x: x² − 4x + 3 = 0 → (x − 1)(x − 3) = 0 → x = 1 y x = 3, así que (1, 0) y (3, 0).
Conexión con el Tema 4: hallar los interceptos con el eje x de una parábola es exactamente resolver una ecuación cuadrática. Puedes factorizar o usar la fórmula cuadrática.

4. Máximo y mínimo en contexto

El vértice resuelve problemas reales: la altura máxima de un proyectil, el beneficio máximo de un negocio, el área máxima de un terreno. Si la parábola abre hacia abajo, el vértice es el máximo.

Ejemplo 3 · El proyectil

La altura es h(t) = −16t² + 64t + 5 (t en segundos). ¿Cuándo alcanza la altura máxima y cuál es?

1 Como a = −16 < 0, abre hacia abajo: el vértice es un máximo.
2 t del vértice: −64 / (2·−16) = −64 / −32 = 2 segundos.
3 Altura máxima: h(2) = −16(4) + 64(2) + 5 = −64 + 128 + 5 = 69 pies.
Ejemplo 4 · El beneficio

El beneficio es B(x) = −2x² + 120x − 800. ¿Cuántas unidades lo maximizan?

1 x del vértice: −120 / (2·−2) = −120 / −4 = 30 unidades.
2 Beneficio máximo: B(30) = −2(900) + 120(30) − 800 = −1800 + 3600 − 800 = 1000.

Tarea

Para hacer por su cuenta, con el cuaderno, papel cuadriculado, la calculadora TI-30XS y la hoja de fórmulas del GED:

  • El proyectil y el beneficio: la altura de una pelota es h(t) = −16t² + 64t + 5 (en pies, con t en segundos). Grafíquela, halle la altura máxima con el vértice y calcule cuándo toca el suelo. Después, halle cuántas unidades x maximizan el beneficio B(x) = −2x² + 120x − 800 y cuál es ese beneficio máximo.
  • Las cuatro características: haga una tabla con la dirección de apertura, el vértice, el eje de simetría y los interceptos de y = x² − 4x + 3, y = −x² + 6x − 5, y = 2x² + 8x e y = x² + 2x + 5. En una de ellas no hay interceptos con el eje x; explique cómo lo sabe.
